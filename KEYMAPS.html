快捷鍵與功能指南

依照常見操作情境整理快捷鍵和插件功能。使用搜尋快速篩選按鍵或功能名稱；本頁是 KEYMAPS.md 的 HTML 版，並非取代它。

快速查找

<Space>ff / <Space>fg開啟檔案或搜尋程式碼 <Space>e / <C-n>切換檔案樹 <Space>gs / <Space>gBGit 狀態與分支操作 <Space>lr重新命名 LSP 符號 <Space>xx開啟診斷清單 <Space>c在下方開啟終端機 <C-g>離開終端機並保留程序 <Space>wc安全關閉檔案或終端機

閱讀方式

  • <Space> 代表空白鍵，也就是 <leader>。例如 <leader>ff 是依序按 Space、f、f。
  • <C-x> 表示 Ctrl+x；<A-x> 表示 Alt+x。
  • 除非另有註明，快捷鍵在 Normal 模式使用。
  • 「LSP 附加時」表示該檔案已有語言伺服器提供功能；目前 C/C++ 主要使用 clangd。
  • 按下 <Space> 後稍候，可透過 which-key 查看可用快捷鍵提示。

視窗與 buffer

快捷鍵功能
<Space>wh / wj / wk / wl移至左／下／上／右側視窗
<Space>ws / wv水平／垂直分割視窗
<Space>wn恢復最近開啟的檔案編輯區；若目前只有檔案樹，保留檔案樹並開回檔案
<Space>wc安全關閉目前檔案 buffer；若目前是終端機，則關閉終端機
<Space>wC強制關閉目前檔案 buffer，丟棄未儲存變更
<Space>wo關閉其他視窗
<Space>w=平均調整所有視窗大小
<Space>Q退出所有視窗
gt / gT切換至下一個／上一個 buffer
<A-l> / <A-h>切換至下一個／上一個 buffer

<Space>wc 不會強制關閉有未儲存修改的檔案；請先儲存或自行放棄變更。關閉終端機時會結束 shell，並盡量保留編輯區與檔案樹。<Space>wC 會直接丟棄未儲存變更。直接輸入 :bd、:q 維持 Neovim 原生行為。

gdNormal，LSP 附加時跳至定義

診斷與錯誤清單

快捷鍵模式功能
[dNormal，LSP 附加時跳至下一個診斷
]dNormal，LSP 附加時跳至上一個診斷
<Space>xxNormal開啟／關閉所有檔案的診斷清單
<Space>xXNormal開啟／關閉目前檔案的診斷清單

收到錯誤或警告診斷後，設定會等待約一秒，再嘗試使用 Bing 翻譯並把繁體中文譯文附加在對應行尾，不必移動游標。譯文沿用錯誤／警告色系並調亮顯示。診斷訊息會傳送至 Bing；翻譯失敗時不顯示通知，並暫停自動重試一分鐘，原始診斷仍正常顯示。

快捷鍵模式功能
sNormal、Visual、Operator-pendingFlash 快速跳轉
SNormal、Visual、Operator-pendingFlash Tree-sitter 跳轉／選取
<Space>mNormal選取游標下單字並加入下一個相同位置；重複按可繼續加入
<C-j> / <C-k>Normal在下方／上方新增多游標

<Tab>多游標編輯切換游標模式與延伸選取模式

Esc多游標編輯結束多游標編輯

<C-j>、<C-k> 與 <Tab> 在 Insert 模式仍用於補全選項。

包覆、文字物件與移動

mini.surround：Normal 模式按 <Space>sa 後接移動／文字物件與符號來新增包覆；Visual 模式按同鍵包覆選取文字。<Space>sd 刪除包覆，<Space>sr 替換包覆。

mini.ai 文字物件可在 Visual 或 Operator-pending 模式使用：

  • a)／i)、a]／i]、a}／i}：選取含括號／括號內的內容。
  • aq／iq：選取含引號／引號內的內容。
  • aa／ia：選取含參數分隔符／參數本身。
  • af／if：選取函式呼叫／呼叫內容。
  • aF／iF：以 Tree-sitter 選取函式定義／函式本體（C、C++、Python）。

mini.move：Normal 模式按 <A-j>／<A-k> 移動目前行；Visual 模式選取區塊後按同組按鍵移動區塊。

補全、括號與註解

Insert 模式快捷鍵功能
<C-j> / <Tab>選擇下一個補全項目
<C-k> / <S-Tab>選擇上一個補全項目
<C-b>手動觸發補全（<C-Space> 保留給輸入法）
<Enter>確認補全項目

補全候選會忽略大小寫與標點符號比較名稱，較短的候選優先顯示。C/C++ 註解中輸入 \ 可補全常用 Doxygen 標籤，例如 \param、\return。

nvim-autopairs 會在 Insert 模式自動配對括號與引號：在配對中按 <BS> 可刪除一對，按 <Enter> 可在括號中間換行。HTML/XML 輸入開始標籤後按 > 會補上結束標籤；編輯標籤名稱時也會同步更名。

Comment.nvim 使用預設映射：gcc 切換目前行註解；gc 加上移動命令可註解選取範圍；gbc／gb 使用區塊註解。

在 C/C++ 中按 <Space>z 可清理游標附近多餘的 )／}。游標必須位於整個檔案中確定成對的 ()／{} 內；若該組括號後方同一行有多出的同類右括號，會刪除距離游標最近的閉合符號，否則刪除最近的不成對右括號。每次只刪一個；掃描會考慮跨行配對並忽略註解與字串，不需要等待 clangd 診斷。

翻譯

一般翻譯可在 Normal 模式將游標放在單字上，或先選取文字；命名風格轉換需先在 Visual 模式選取文字。

快捷鍵模式功能
<Space>teNormal／Visual中翻英，結果顯示於游標附近彈窗
<Space>tzNormal／Visual英翻中，結果顯示於游標附近彈窗
<Space>tseNormal／Visual中翻英，以通知顯示結果
<Space>tszNormal／Visual英翻中，以通知顯示結果
<Space>tteVisual中翻英並轉為小寫底線命名（snake_case）
<Space>tTEVisual中翻英並轉為常量命名（UPPER_SNAKE_CASE）
<Space>ttEVisual中翻英並轉為小駝峰（camelCase）
<Space>tTeVisual中翻英並轉為大駝峰（PascalCase）
<Space>tEVisual中翻英並轉為小寫空格分隔
<Space>ttzVisual英翻中並以原始翻譯文字替換

翻譯彈窗會自動調整尺寸並使用圓角邊框，按 q、Esc 或 Enter 關閉。翻譯使用 Bing 網路服務。

終端機

快捷鍵模式功能
<Space>/Normal在新分頁開啟內建終端機並進入輸入模式
<Space>cNormal在目前視窗下方開啟內建終端機並進入輸入模式
<C-g>Terminal返回上一個 buffer，保留終端機程序
<C-q>Terminal關閉終端機並結束 shell 程序
Ctrl+\，接著 Ctrl+nTerminal返回 Normal 模式
iNormal，終端機 buffer返回終端機輸入模式

終端機文字使用橘色顯示。在終端機輸入 :q 會把文字送給 shell，而不是執行 Neovim 命令。要暫時離開並保留 shell，按 <C-g>；要結束 shell 並關閉終端機，按 <C-q>。也可按 Ctrl+\、Ctrl+n 離開終端機模式，再執行 :q 關閉視窗；此方式不會結束 shell 程序。

設定與環境檢查

命令／快捷鍵功能
<Space>r重新載入 init.lua 與 config.editor
:NvimCheckEnv手動檢查 Git、GCC、LLVM clangd 與 Tree-sitter parser 等外部依賴
:MasonInstall clangd透過 Mason 安裝 clangd

Neovim 啟動後會自動檢查外部依賴；若有缺少，會列出名稱和用途。重新載入設定後，已載入插件的設定變更可能仍需重開 Neovim。

主要功能

  • C/C++ 開發：Mason 管理 clangd，提供補全、符號導覽、診斷與格式化；函式及條件區塊 scope 提示使用亮色粗體、不加底線；格式化使用 4 格縮排設定。
  • 語法與括號：Tree-sitter 支援 C、C++（.ino 以 C++ 開啟）、Lua、Vim、Vim help、Markdown、Python、JSON、HTML 與 XML；.bat 使用 Neovim 內建語法高亮；彩虹括號使用三色循環；Doxygen 標籤以金色粗體顯示並支援補全。
  • Git：vim-fugitive 提供互動式狀態／差異檢視與 Git 命令；Gitsigns 在行側標示修改區塊。
  • 檔案導覽：NvimTree 檔案樹與 Telescope 檔案、文字及 buffer 搜尋。
  • 編輯輔助：nvim-cmp 補全、nvim-autopairs 括號配對、nvim-ts-autotag HTML/XML 標籤配對、mini.surround 包覆操作、mini.ai 文字物件、mini.move 區塊移動、Trouble 診斷面板、Comment.nvim 註解、Flash 快速跳轉及 vim-visual-multi 多游標編輯。
  • 介面：Tokyo Night 主題、透明背景、絕對／相對行號、縮排導引線、Bufferline、Lualine 狀態列、Scrollbar 與診斷提示；游標及捲動畫面不使用動態動畫。
  • 翻譯：Bing 英中翻譯、命名風格替換，以及診斷訊息自動翻譯。

設定檔位置

  • lua/config/editor.lua：基本選項、一般快捷鍵、視窗與終端機行為。
  • lua/config/plugins.lua：插件規格、插件設定與 LSP 快捷鍵。
  • lua/plugins/：個別插件設定，例如翻譯與 Fugitive 中文標題。

快捷鍵或插件功能有變更時，請同步更新 KEYMAPS.md 與本 HTML 指南；按 <Space>h 開啟 Markdown 版，按 <Space>H 開啟互動 HTML 版。
